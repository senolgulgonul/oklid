# Öklid Elementler

Cetvel ve pergelle oynanan tarayıcı oyunu. Öklid'in *Elementler*'indeki çizim önermelerini, kitabın sırasıyla ve kitabın kurallarıyla çözdürür: cetvel ölçmez, pergel açıklık taşımaz, yeni nokta yalnız kesişimde doğar. Kazanılan her önerme sonraki seviyede tek hamlelik araç olur.

**Oyna:** https://senolgulgonul.github.io/oklid/

Tek HTML dosyası, sunucu yok, hesap yok, veri toplama yok. Telefonda ve masaüstünde çalışır. Dış bağımlılık yalnız Google Fonts (Literata).

## Çalıştırma

`index.html` dosyasını tarayıcıda açmak yeter. Yayın GitHub Pages ile (Settings → Pages → main / root).

## Kısayollar

D cetvel, P pergel, E eşkenar üçgen, T taşınmış pergel, A açıortay, O orta nokta, K dikme, L paralel, Q kare · Z geri al, R baştan, S sığdır, Esc seçimi temizle.

Teknik ayrıntı ve genişletme fikirleri için `OKLID_OYUNU.md`.
